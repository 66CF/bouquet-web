# 花间 FLEUR

一间数字花房。基于 Three.js 的可交互玫瑰花束，支持原貌、微光、散开、聚合、写字和自动流转。采用深绿与暖粉配色、响应式展台布局和可响应灯光的花瓣材质。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖、无需构建：

```sh
npm start
```

访问 <http://127.0.0.1:8765/>，按 `Ctrl+C` 停止。Windows 也可双击 `start.bat`。服务器仅监听本机；端口被占用时可以指定 `PORT` 环境变量。

也可用 Python 运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

必须通过 HTTP 访问，不能直接双击 `index.html`。页面依赖 WebGL 2；Three.js、字体回退与花束模型均在本地，不依赖 CDN。部署时将页面、`css`、`js`、`assets`、`vendor` 一并上传到静态服务器即可。

## 操作

| 入口 | 效果                                               |
| ---- | -------------------------------------------------- |
| 原貌 | 柔光下的完整花束                                   |
| 微光 | 沿花束表面分布的细小光点                           |
| 散开 | 粒子沿弧线向外散开                                 |
| 聚合 | 将粒子重新聚合成花束                               |
| 写字 | 三股光带盘旋后逐步落成连笔 `ZWC`，文字始终面向相机 |
| 流转 | 自动循环花束形态，再次点击停留在当前状态           |
| 调整 | 粒子数量、大小、散开距离、柔光、旋转与视角复位     |

拖拽旋转、滚轮缩放；触屏支持单指旋转与双指缩放。设置面板支持 Escape 关闭和键盘操作。

## 结构

```text
index.html                语义页面、控制入口与加载反馈
css/style.css             花房视觉、移动布局与减少动态效果支持
js/
  bootstrap.js            动态入口与启动错误兜底
  main.js                 加载、渲染生命周期与模块协调
  config.js               统一默认参数、模式文案与拼字内容
  scene.js                渲染器、相机、柔光环境和材质转换
  particles.js            表面采样、纹理取色、文字目标与粒子缓冲
  particle-material.js    GPU 粒子运动、三股书写光流与光点着色器
  text-targets.js         本地连笔字体加载与细笔画目标采样
  animation.js            可暂停的统一补间/延迟时钟
  effects.js              六种效果及自动循环状态
  ui.js                   控件绑定、模式提示和设置面板
  loading.js              进度、加载完成和失败重试
  utils.js                确定性随机数、颜色转换与任务让步
scripts/                  零依赖静态服务器和语法检查
tests/                   动画与效果状态的回归测试
assets/                   花束 GLB 模型
vendor/three/             仓库自带的 Three.js 模块
```

修改 `js/config.js` 的 `text` 可调整拼字内容，调整粒子数量和默认参数也在此处进行。灯光、曝光、镜头取景与材质参数位于 `js/scene.js`。

## 渲染和性能

- 原模型采用 `KHR_materials_unlit`。加载后转换为保留原贴图的物理材质，使柔光、环境光和花瓣表面高光生效；原始 GLB 文件不修改。
- 表面粒子按面积均匀采样，分批让出主线程。复用位置、颜色、文字数组，并用查找表进行 sRGB 转换。
- 桌面默认 10 万粒子，粗指针设备默认 6 万，可调整到 18 万。数量变化只更新绘制范围，不重新生成缓冲。
- 桌面像素比上限为 2，粗指针设备为 1.5。关闭柔光时绕过后期处理。
- 页面进入后台时暂停渲染与动画时钟。关闭旋转且原貌静止时按需重绘；粒子模式保留轻微呼吸。
- 系统设置减少动态效果时默认关闭自动旋转及界面动效，仍可主动触发花束效果。
- WebGL 初始化、模型加载失败和上下文丢失均提供重载入口。

模型文件约 23 MB，首次打开仍需下载并解码模型；移动端性能取决于设备 GPU。本次保留模型贴图与几何精度。

## 检查

```sh
npm run check
npm test
```

测试覆盖补间衔接、延迟取消、写字中断、全部手动形态、循环启停与手动退出循环。视觉检查应包含桌面、手机竖屏、窄屏设置面板及不同粒子形态。

## 字体

写字模式使用本地 [Great Vibes](https://github.com/google/fonts/tree/main/ofl/greatvibes) 连笔字体，遵循 SIL Open Font License 1.1。字体与许可证位于 `assets/fonts/`，部署时需一并保留。字体加载失败时回退到系统衬线斜体。
